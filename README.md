# 监控分析器（Video Active Frame Deleter）

简体中文 | [English](README.en.md)

剔除监控视频中的静止（无用）帧，只保留发生有效运动的画面，并输出精简视频与报告。

![界面预览](docs/screenshot.png)

**下载便携版**：无需安装 Python，到 [Releases](../../releases) 页面下载
`监控分析器_portable.zip`，解压后运行 `监控分析器.exe` 即可。

## 功能

- **输入视频**：mp4 / avi / mkv / mov / ts / flv / wmv / webm（OpenCV 支持的格式）。
- **分析区域**：在预览帧上直接拖拽框选**只参与分析的区域**（可多个），例如大门口、
  车道等运动需要关注的位置；**不框选则分析整个画面**。画面上叠加的时间数字等
  放在框外即可自动忽略。
- **两级阈值**：
  - *像素敏感度（0-255）*：单个像素变化多大才算"变了"（默认 25）；
  - *有效变化阈值（%）*：分析区域内变化像素占比达到多少才算"有效运动帧"
    （默认 0.5%，即题目中的"百分之多少的变化"）。
- **片段合并**：运动开始前/结束后自动多保留若干帧（可调），两次靠近的运动自动合并，
  避免输出碎片化。
- **输出**：
  - 剔除后的视频（默认 `<原名>_剔除后.mp4`，编解码不可用时自动回退 AVI/XVID）；
  - 可在输出帧上**烧录原始时间戳水印**（抽帧后时间轴会压缩，水印用于回溯原始时刻）；
  - CSV 报告（每帧的时间、变化率、是否保留，UTF-8 BOM，Excel 可直接打开）；
  - 可选：保留帧另存为图片。
- **后台分析**：带进度条、实时统计与实时预览（当前画面 + 变化像素标红），可随时取消。
- **多线程分片**：长视频自动按线程数分片并行解码分析（默认"自动"按 CPU 核数，
  最多 8 线程；也可手动指定 1-32，1 为单线程顺序模式），结果与单线程完全一致。
- **结果先预览再保存**：分析完成后在内置播放器中预览结果视频（播放/暂停、
  拖动进度条），确认后再点 **保存结果…** 选择保存位置——视频、CSV 报告、
  保留帧图片会按所选位置自动配套保存；不想要可一键"放弃结果"。

### 实时监控（新）

主窗口第二个标签页：**实时读取屏幕上框选的区域**（可多屏、可多个区域，每个区域
独立分析、独立出结果）——适合盯电子看门画面、网页监控流、直播画面等。

- 点击 **框选区域** 进入全屏覆盖层，**两级框选**：
  1. **监控区域**（绿框，捕获与录像范围）：拖拽完成一个即自动设定，
     **按 A 键框选下一区域，按回车键退出框选**（Esc 取消全部 / 右键矩形删除）；
  2. **按 S 键切换到分析区域**（蓝框，只让框内变化计入分析，如把时间数字留
     框外即可忽略）：同样 A 键画下一个、回车退出、右键删除；分析矩形自动裁剪
     到所属监控区域内；**不框分析区域 = 整个监控区域参与分析**。覆盖层上有
     实时按键提示条；
- 每个区域一张卡片：实时画面预览、当前变化率、运行状态；
- 变化率连续超过阈值即记为一次 **运动事件**：记录开始/结束时间、峰值/平均变化率，
  勾选"保存运动片段"时每个事件自动存为 mp4 片段（默认关闭则只记 CSV）；
- 勾选 **合并输出**：停止监控后**每个区域的全部运动片段自动合并为一个视频**
  （`区域N_合并_时间戳.mp4`，按事件顺序逐帧拼接）；
- 停止后自动生成 `事件报告_时间戳.csv`（默认保存在 `视频\监控分析器_实时`，可改）；
- 参数：采样帧率（默认 15fps）、像素敏感度、有效变化阈值、事件前后保留秒数。

### 批量分析（新）

主窗口第三个标签页：**一次拖入多个视频同时分析**（点击"添加视频/添加文件夹"）。

- **每个视频独立的分析区域**：双击视频列表中的行，进入该视频的分析区域
  编辑界面（可前后翻帧查看画面，拖拽框选多个区域；时间数字等固定内容留在
  框外即可忽略）。确认后列表"分析区域"列显示 **已编辑 N 个区域**；
  未编辑的视频按**全画面**分析；
- 每个视频一行：状态、进度、结果实时刷新；"同时分析数"可设 1-4（默认 2）；
  并发大于 1 时各视频内部自动单线程，避免争抢 CPU；
- 全部完成后可直接双击结果列打开输出文件；失败行悬停可看原因，支持一键取消全部；
- 输出文件名与单视频模式一致（`<原名>_剔除后.mp4`），默认保存在各自视频旁，
  也可勾选"输出到指定目录"统一存放；CSV 报告、时间戳水印按需勾选。

## 使用步骤

1. 双击 `run_dev.bat`（开发目录）或解压便携包后双击 `监控分析器.exe`；
2. 点击 **选择视频…**，载入监控视频；
3. 在预览上**拖拽框选分析区域**（只分析框内画面，可多个；不框选=全画面分析，
   时间数字等放在框外即可忽略）；
4. 设置**像素敏感度**与**有效变化阈值**（百分比），按需调整前后保留帧数与并行线程数；
5. 点击 **开始分析**，等待进度完成；
6. 在内置播放器中预览结果，点 **保存结果…** 选择位置导出（视频 + CSV 报告
   + 保留帧图片自动配套保存），或点 **放弃结果** 丢弃本次分析。

实时监控与批量分析在主窗口顶部的标签页中切换，操作均为"配置参数 → 开始 →
查看结果表/卡片"。

## 参数建议

| 场景 | 像素敏感度 | 有效变化阈值 |
|---|---|---|
| 白天、画质干净 | 20-30 | 0.3 - 1 % |
| 夜间、噪点多 | 35-50 | 0.5 - 2 % |
| 只想抓大动作（人/车） | 25-40 | 2 - 5 % |

## 性能

v1.2 起内置三项提速手段，默认全部启用：

- **跳跃导出**：按保留段 seek 跳过无运动区间解码，丢弃帧越多越快。
- **多线程分片**：长视频自动分段并行解码分析（线程数选「0=自动」）。
- **高速模式（可选，默认关闭）**：宽于 1280 像素的视频降采样后分析，明显提速，
  但细小/微弱目标（远处火焰、小动物）可能漏检；行人、车辆等较大目标不受影响。

实测参考（i9 32 线程，1920x1080@25fps，含导出与水印）：

| 素材 | v1.1.1 | v1.2 |
|---|---|---|
| 11 秒短片（281 帧） | 3.4 s | 3.1 s |
| 5 分钟长视频（7500 帧，10% 保留） | 67 s | **32 s** |

```bat
build.bat
```

## 常见问题

- **输出视频比原视频"短"很多？** 剔除帧后同一帧率下时长自然缩短；
  输出帧上的时间戳水印显示的是原始时间。
- **运动片段被漏掉？** 调低"有效变化阈值"或调低"像素敏感度"再试。
- **静止画面被大量误保留？** 多为夜间噪声或压缩噪声：调高像素敏感度，或只框选
  真正需要关注的分析区域（把天空、树梢等放框外）。
- **选择视频后预览空白 / 提示无法读取画面？** 多为该视频使用了系统缺失
  解码器的编码格式（如部分 H.265/HEVC 或非常规封装）。先用播放器确认视频
  本身可播；若播放器可播而本软件不行，请用格式工具转为 H.264 MP4 后再试。
- **长视频分析慢？** "并行线程数"保持 0（自动）即可多线程分片加速；
  机械硬盘上建议把视频先复制到本地磁盘。

## 版本历史

- **v1.7**：实时监控升级为**两级框选**——监控区域（绿框）之内还能框选**分析区域**
  （蓝框），只让分析子区域内的画面变化计入运动判定（时间数字等固定内容放框外
  即可忽略）；**按 S 键**在监控/分析模式间切换，分析矩形自动裁剪到所属监控区域，
  不框分析区域=整个监控区域参与分析。
- **v1.6**：实时监控两项升级——①屏幕框选改为**逐个设定**：拖拽完成一个区域即
  设定，按 **A** 键框选下一区域、按**回车**键退出框选，界面有按键提示；
  ②新增**合并输出**选项：勾选后停止监控时每个区域的全部运动片段自动
  合并为一个视频。
- **v1.5**：批量分析支持**每个视频独立的分析区域**——双击视频行打开编辑界面
  （可翻帧预览、拖拽框选多个区域），确认后列表显示"已编辑 N 个区域"，
  未编辑的视频按全画面分析。
- **v1.4.1**：修复两个问题——①分析完成后不保存、直接打开新视频时，画布上仍残留
  上一个视频的分析区域框（右侧列表却为空）；②分析过程中右下角实时预览面板
  逐帧棘轮式变大（首帧后每次 +2px），分析结束后保持放大尺寸不再恢复。
- **v1.4**：新增**实时监控**与**批量分析**两个标签页。实时监控：屏幕上框选任意
  区域（支持多屏、多区域），每个区域独立分析、独立卡片实时预览与变化率显示，
  运动事件记录 CSV、可选自动保存运动片段 mp4；批量分析：一次加入多个视频
  （文件或整个文件夹）并发分析（1-4 路），逐行进度/状态/结果，支持一键取消。
- **v1.3**：①"剔除区域"改为更直观的"**分析区域**"——只在框选的区域内分析运动
  （不框选=全画面），时间数字等放框外即可忽略；②分析过程中的实时预览升级为
  当前画面 + 变化像素标红（不再显示黑乎乎的差异掩码）；③修复长视频分析时
  统计文本与预览长时间不刷新的问题（按时间节流持续更新）。

- **v1.2**：大幅提速——保留段跳跃导出（跳过无运动区间不解码）、多线程分片
  （长视频自动并行）、可选高速降采样模式（默认关闭）；进度显示处理速度。
- **v1.1**：修复"分析一次后无法再次分析"；新增多线程分片处理；分析结果改为
  软件内预览 + 手动另存（不再直接写文件）；打开视频时校验可解码性并明确报错；
  帧读取失败自动回退重试。
- **v1.0**：首个版本。
